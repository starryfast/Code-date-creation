## 二、二十重境界能力全解

二十项能力统一由 `cdcfantasy.dll` 提供，前端通过 `/api/fx` 通道调用。  
能力清单由 `CDC_FX_LIST()` 导出，每项包含 `no / op / name / kind / desc / in` 六个字段。

### 1. FNV-1a 哈希（op: `fnv1a`）

Fowler–Noll–Vo 1a 变体哈希。对输入逐字节做异或与乘法，常用于快速字符串指纹。

- 输入：字节串
- 输出：64 位无符号整数
- 用途：文件快速判重、分片路由、缓存键

### 2. MurmurHash3（op: `murmur3`）

MurmurHash3 x64_128 截断版本，标准 seed = 0。速度比 FNV 更快，  
分布更均匀，适合较大数据集。

- 输入：字节串
- 输出：64 位无符号整数
- 注意：实现必须使用标准 seed=0，否则对拍失败

### 3. 前缀哈希（op: `prefix`）

对输入取前 N 字节计算哈希，用于超长数据的快速采样比对。

### 4. 最长递增子序列（op: `lis`）

经典 LIS，动态规划 O(n²) / 贪心 + 二分 O(n log n)。

- 输入：整数序列
- 输出：最长长度与方案数

### 5. 最长下降子序列（op: `lds`）

LIS 的对称形式，常与 LIS 配合判断最长双调序列。

### 6. 逆序对（op: `inversions`）

逆序对计数，归并排序实现 O(n log n)。

- 输入：整数序列
- 输出：逆序对数量

### 7. 中位数（op: `median`）

偶数个元素取中间两个的算术平均。

### 8. 平均绝对偏差（op: `mad`）

MAD = 平均(|xᵢ - mean|)，对离群点比标准差更稳健。

### 9. 四分位距（op: `iqr`）

IQR = Q3 - Q1，用于箱线图与离群判定。

### 10. IQR 离群检测（op: `outlier_iqr`）

以 [Q1 - 1.5·IQR, Q3 + 1.5·IQR] 为正常区间，区间外判为离群。

### 11. Z-score 离群检测（op: `outlier_z`）

|z| > 阈值（默认 3）判为离群。适合近似正态分布的数据。

### 12. 皮尔逊相关系数（op: `pearson`）

r = Σ(xᵢ-x̄)(yᵢ-ȳ) / √(Σ(xᵢ-x̄)²·Σ(yᵢ-ȳ)²)，取值 [-1, 1]。

- 注意：两侧样本数必须一致，否则报错

### 13. 最小二乘斜率（op: `slope`）

对散点拟合 y = kx + b，返回斜率 k。

### 14. 最大公约数 / 最小公倍数（op: `gcdlcm`）

辗转相除求 GCD，lcm = a / gcd · b。

### 15. 质因数分解（op: `factor`）

试除法分解质因数，输出形如 `2^3 · 3^2 · 5`。

### 16. 素性判定（op: `isprime`）

确定性 Miller–Rabin 小范围判定。

### 17. 模幂（op: `modpow`）

快速幂求 aᵇ mod m，用于 RSA/扩散函数模拟与生成器算法验证。

### 18. 最小生成树（op: `mst`）

Prim 算法。注意：**非连通图会失败**，必须保证输入连通。

### 19. 最短路（op: `dijkstra`）

Dijkstra 求单源最短路，边权非负。

### 20. 游程编码（op: `rle`）

游程编码，压缩连续重复段，常与重复序列生成配合。

### 对拍验证

二十项能力均有独立对拍器，参考实现与 DLL 实现在大数据集上逐一比对，  
确保边界（空输入、单元素、全等、极值）下结果一致。

## 三、C++ 在线运行器

无需本地编译环境，在程序内直接写、编译、运行 C++ 代码。

### 使用流程

1. 打开「C++ 运行器」（工具页或独立弹窗入口）
2. 在弹出编写框中输入代码 —— **语法高亮、行号槽、Tab 缩进、括号配色**均已内置
3. 点击「运行」，后端将代码写入临时 `.cpp`
4. 调用随包 MinGW g++ 编译
5. 带超时执行，捕获标准输出回显

### 后端接口

```
POST /api/run
{ "code": "..." }
→ { "ok":true, "stage":"detect|write|compile|run",
    "exitCode":0, "timedOut":false, "output":"..." }
```

`stage` 用于定位失败环节：

| stage   | 含义       | 排查方向             |
| ------- | -------- | ---------------- |
| detect  | 环境探测失败   | MinGW 路径、编译器是否随包 |
| write   | 临时文件写入失败 | 磁盘权限、临时目录        |
| compile | 编译失败     | 看 output 中的编译器报错 |
| run     | 运行失败或超时  | 死循环、无输出          |

### 常见问题

**Q：提示找不到 g++？**  
A：确认 exe 同级存在 `mingw64/bin/g++.exe`。单文件 exe 若剥离了工具链，  
需要改用「写文件 + 编译」的传统两步流程。

**Q：代码没有输出？**  
A：`cout` 需要 `ios::sync_with_stdio(false)` 更快但不影响有无输出；  
若使用 `printf`，请包含 `<cstdio>`。

**Q：程序卡住不动？**  
A：后端设有超时保护，超时后会强杀进程并返回 `timedOut:true`。

## 六、安全凭据生成器

使用浏览器原生 `crypto.getRandomValues()` 取随机字节。

### 为什么用「拒绝采样」

直接从 `n` 个取值里按 `字节 % n` 取模会产生**取模偏置**：  
当 256 不能被 n 整除时，靠前的取值会被多选中。本生成器的做法是  
循环取随机字节，直到落在 `[0, n·⌈256/n⌉)` 区间内再取模，从而保证均匀。

### 类型

| 类型      | 说明               |
| ------- | ---------------- |
| 强密码     | 长度可调，字符集可勾选      |
| 字母数字    | 仅大小写字母 + 数字      |
| 十六进制    | 十六进制串            |
| UUID v4 | 标准 8-4-4-4-12 格式 |
| Base58  | 去除易混字符 0 O 1 l I |

界面实时显示**熵值（bits）**，便于判断强度是否达标。

## 九、部署与云端

### 云端地址

开源版**不内置任何云端服务器地址与接口令牌**，默认进入纯本地模式：数据生成、编译、对拍、幻想引擎等全部功能均在本机运行，无需联网。

如需接入**自建**后端，在 exe 同目录放一个 `cdc_srv.dat`，内容：

```
server=<你的云端地址，十六进制 XOR 编码>
```

程序启动时会读取该文件并解码填入云端地址（格式与 `cdc_backend.cpp` 中 `XorDecodeHex` 一致）。  
未配置时云端账号、AI 代理、激活码等联网功能不可用，但本地功能不受影响。

> 注意：`kCloudXorKey` 仅用于本地配置解码，不是保密密钥；真正需要保密的是你自建服务端的地址与令牌，请勿明文写入仓库。

用户总数统计、私聊管理、API 绑定设备管理、批量 AI 激活码生成、  
用户增删封禁、加密存储、用户名查重、弱密码检测。

## 十、性能要点

程序针对 Intel 核显卡做过专项优化：

- 禁止 `background-attachment: fixed`（滚动必重绘），改用固定定位层
- 避免大面积毛玻璃 `backdrop-filter`
- 动效只使用 `transform` / `opacity`（走 GPU 合成）
- 遵循 `prefers-reduced-motion`，系统关闭动画时自动降级

## 十一、常见问题排查

**Q：界面细节显示旧版本？**  
A：程序可能被旧副本覆盖运行。检查安装目录与「打包/Output」下的历史安装包，  
删除后重新出包。

**Q：云端连不上？**  
A：多为混淆密钥与密文不匹配，或本地配置文件被改写。核对版本号、  
密钥与地址三者是否配套。

**Q：编译出的 exe 被占用无法覆盖？**  
A：先结束正在运行的 `cdc_backend.exe` 进程再重编。

**Q：MST 报错？**  
A：输入图必须连通，非连通图请先补边或改用连通分量。
