# Code date creation · 官网（PHP）

深色工作台风格的官网。设计立意是**让官网本身就长得像 CDC 这个程序**：
顶部是窗口标题栏、左侧是功能栏、底部是状态栏，整站是一块"正在运行的软件界面"。

- **纯 PHP**，无框架、无构建步骤、无 CDN 请求
- **零扩展依赖**（特别是不需要 `mbstring`，很多虚拟主机默认没开）
- PHP **7.4+**，不需要写权限、不需要数据库

---

## 页面

| 文件 | 说明 |
|---|---|
| `index.php` | 工作台：Hero（含 CSS 手绘的程序界面 + 终端动画）、数据条、九块功能、四步工作流、造数据方式标签页、技术内幕入口、版本记录（git log 样式）、下载、署名与鸣谢、FAQ |
| `source.php` | 技术内幕：左侧按模块分组的源码目录，右侧一次打开一章（`?c=t4` 可直接分享单章链接） |
| `guide.php` | 使用手册：九个章节 + 左侧目录 + 滚动时自动高亮 |
| `download.php` | 下载：最新版卡片、运行要求、全部历史版本表（含提取码）、逐版本变更记录 |

## 目录

```
inc/data.php          ★ 唯一数据源：版本 / 下载 / 署名 / 链接 / 功能 / 模式 / FAQ / 终端脚本
inc/source_data.php   ★ 技术内幕的 16 章正文（区块数组，对照 v7.1.0 源码）
inc/lib.php           工具函数：转义、行内标记、C++ 高亮、区块渲染、导航
inc/shell_open.php    外壳上：文档头 + 标题栏 + 侧边栏
inc/shell_close.php   外壳下：页脚 + 状态栏 + 脚本
data/versions.json    ★ 版本历史（首页时间线与下载页表格共用）
assets/app.css        全部样式（含配色变量）
assets/app.js         时钟 / 终端打字 / 标签页 / FAQ / 平滑锚点 / 滚动高亮
```

## 改内容

| 想改什么 | 改哪里 |
|---|---|
| 版本号、下载直链、组织署名、FAQ、功能列表 | `inc/data.php` |
| 新增一个版本 | `data/versions.json` 的 `versions` 数组**开头**插入一项 |
| 技术内幕正文 | `inc/source_data.php`，块类型见 `cdc_block()` |
| 配色 | `assets/app.css` 顶部的 `:root` 变量 |

正文区块支持 `p · h3 · h4 · ul · ol · code · table · note`；
行内可用 `` `代码` `` 与 `**加粗**`；`code` 块会自动做 C++ 高亮。

## 部署

整个目录传到站点根（或任意子目录）即可 —— 全站都是相对链接，不用改任何配置。

本地预览：

```bash
php -S 127.0.0.1:8000
```

## 注意

- 站内唯一需要联网的是**外链**（GitHub / GitCode / B站 / ACGO 等）；页面本身不发任何外部请求。
- 技术内幕的正文以作者自撰的开发笔记为准，并**逐段对照 v7.1.0 源码**核实
  （后端 `cdc_backend.cpp`、前端 `index.html` + `cpp_bridge.js`、原生端 `WindowsProject1.cpp`、
  云端 `cdc_server/*.php`、库 `cdc_lib/cdcscq.hpp`）。
  **不要往里面写没有在源码里验证过的说法。**
- 旧站首页曾出现「AST 驱动 / Mersenne Twister / mmap / 提速 40%」之类的描述，与源码不符，已全部剔除。
- 技术内幕描述的是 **v7.1.0 的做法**。v7.0.0 的少数旧实现（注册表持久化、手写 ZIP + CRC32、
  `_wsystem` 重定向）已不再作为卖点，正文中只在「版本对比」处提及，不要写回功能描述里。
