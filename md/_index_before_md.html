🧩 生成器代码 CDCSCQ

              

                在这里直接写 C++ 生成器（可 #include <cdcscq.hpp>），点「编译并生成」会自动：
                编译 → 对每个数据点运行 → 输出直接存成 1.in、2.in…
                （代码里用 case_id() 取当前编号，可按编号造递增规模 / 极端数据）。

                生成器把数据写 stdout 即可；.out 仍用「自编译」页拿你的 AC 代码对这些 .in 跑出来，流程不变。
              

              

                
                
                
              

              
              
              

                
                
                
                
                
              

              

            

          

        


        
        

          

            
C++ 编译运行

            
用 g++ 把 .cpp 编译为 .out 并运行（.out 运行结果写回 .out 文件，与生成器配合完成"编译 + 验证"）。
